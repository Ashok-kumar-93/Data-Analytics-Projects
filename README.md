# Data-Analytics-Projects
Developed an interactive Excel dashboard to analyze sales, profit, and quantity using the Sample Superstore dataset. Used Pivot Tables, charts, and slicers to identify top-performing products, regional sales trends, and profitability insights for better business decision-making.
# Power-Bi-dashboard
Developed an interactive HR Analytics Dashboard using Power BI to analyze employee attrition across 300 employee records. Used DAX, KPIs, charts, and slicers to identify attrition trends based on age, education, salary, and tenure, supporting data-driven HR decisions.
